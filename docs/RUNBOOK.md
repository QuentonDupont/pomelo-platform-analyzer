# Runbook

## Run locally
```
npm install
npm run dev          # http://localhost:3210
npm test             # metric + reconciliation tests
npm run typecheck
```

## What is real vs sample (MVP, 2026-10-08)
| Panel | Source |
|---|---|
| D1 scorecard badged **REAL** | `discovery/superset/weekly_aggregates.json` — Superset dataset 63 (Cube-PROD `segment_session`), 2 weeks |
| Release timeline + cards | `discovery/github_releases.json` — real prod deploy workflow runs (www, api, mobile-ios; android tags only) |
| KPI tiles, bounce court, funnel, sample D1, D2 opportunity board | **SAMPLE** fixture `lib/sample.ts` (CEO-brief totals + illustrative splits) |

## Refresh
Phase 0 discovery files are re-generated by `scripts/phase0_write_discovery.py` (Superset, read-only) and the GitHub discovery scripts.
UI polls `/api/metrics` every 60 s; pulse goes amber after 2 missed refreshes, red on failure.
Scheduled sync jobs (`server/jobs/*`) are Phase 2.

## Add a metric
Define it in `lib/metrics.ts` (single source of truth), add a unit test in `tests/`, then reference it from the UI.

## Add a repo
Append to `GITHUB_REPOS`; document its production deploy signal in `docs/GITHUB_RELEASES.md` (merge time and GitHub Releases are NOT go-live here).
